# SignalDesk

**AI-аналитик глобального и российского рынков с веб-дашбордом.** SignalDesk читает свежие
финансовые новости (25 RSS-лент ведущих изданий и, если хотите, публичные Telegram-каналы).
Быстрая модель отбирает важное, затем подтягиваются котировки, и reasoning-модель DeepSeek
выдаёт сигналы **ПОКУПАТЬ / ДЕРЖАТЬ / ПРОДАВАТЬ** отдельно по глобальному и российскому рынкам.

Приложение работает локально в Docker-контейнере. Дашборд открывается в браузере по адресу
http://localhost:8000.

## Быстрый старт на Mac

Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/). Подходит и для Apple
Silicon, и для Intel.

```bash
git clone <url-репозитория> signaldesk && cd signaldesk
cp .env.example .env        # впишите OPENROUTER_API_KEY
docker compose up -d --build
open http://localhost:8000
```

Нажмите **«Запустить анализ»**. Один прогон занимает 2–4 минуты, в шапке видно, на каком он этапе.

Полезные команды:

```bash
docker compose logs -f      # логи
docker compose restart      # после правки .env
docker compose down         # остановить
git pull && docker compose up -d --build   # обновиться
```

Отчёты и настройки хранятся в папке `./data` рядом с проектом и переживают перезапуски
и пересборки контейнера.

## Дашборд

- **Дашборд.** Счётчики сигналов, настроение глобального и российского рынков, общая картина
  и ключевые драйверы. Таблица сигналов с фильтрами по рынку и действию, поиском и сортировкой;
  по клику строка раскрывается: обоснование, риски и ссылки на новости-источники. Карточки
  котировок со спарклайнами за месяц. Риски, события, за которыми стоит следить, и все новости,
  на которых построен анализ (с важностью и упомянутыми активами).
- **История.** Все прошлые отчёты: открыть, скачать в Markdown или удалить.
- **Настройки.** Список наблюдения (портфель), Telegram-каналы, окно новостей, число статей,
  включение и отключение отдельных лент. Изменения сохраняются в `data/config.yaml`.

Есть светлая и тёмная темы (по системной настройке или переключателем ◐).

## Как это работает

```
RSS (25 лент) + Telegram ─► дедупликация, фильтр по свежести
        │
        ▼
FAST_MODEL: оценка заголовков, отбор top-N ссылок (поровну по регионам)
        │
        ▼
загрузка полных текстов (trafilatura) ─► FAST_MODEL: выжимка, тикеры, сентимент
        │
        ▼
котировки: Yahoo Finance (глобальные) + ISS Мосбиржи (РФ)
        │
        ▼
REASONING_MODEL (DeepSeek R1): обзор, драйверы, сигналы с горизонтом, уверенностью, рисками
        │
        ▼
data/reports/<дата>.json + .md ─► дашборд
```

**Источники по умолчанию** (`signaldesk/sources.py`):
- Глобальные: Bloomberg, FT, WSJ, MarketWatch, CNBC, Yahoo Finance, Investing.com, Seeking Alpha,
  Federal Reserve, OilPrice, CoinDesk.
- Российские: РБК, Интерфакс, Коммерсантъ, Ведомости, ТАСС, ПРАЙМ, Smart-Lab, Investing.com RU,
  Frank Media, Банк России.

Если лента недоступна, она пропускается, и это не прерывает анализ.

## Настройки `.env`

```env
OPENROUTER_API_KEY=sk-or-...
REASONING_MODEL=deepseek/deepseek-r1          # итоговый анализ
FAST_MODEL=google/gemini-2.5-flash-lite       # отбор ссылок и выжимки
AUTO_RUN_HOURS=0                              # авто-анализ каждые N часов (0 — выкл.)
```

Подойдёт любая модель из каталога [OpenRouter](https://openrouter.ai/models). Один прогон
обычно стоит несколько центов: быстрая модель обрабатывает около 30 запросов, reasoning-модель
вызывается один раз. После изменения `.env` выполните `docker compose restart`.

## Telegram

Каналы читаются через публичное веб-превью `https://t.me/s/<канал>`, поэтому API-ключи не нужны.
Подходят открытые каналы с включённым превью. Добавить канал можно на вкладке
**Настройки**: по одному в строке, в виде `markettwits`, `@channel` или `https://t.me/channel`.

## Без Docker (для разработки)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m signaldesk serve            # дашборд на http://127.0.0.1:8000
python -m signaldesk run -m russia    # разовый анализ в консоли
pip install pytest && pytest -q       # тесты
```

Флаги `run`: `-m all|global|russia`, `--hours N`, `-n N` (сколько статей читать),
`-t канал …` (дополнительные Telegram-каналы), `-c config.yaml`, `-q` (не печатать отчёт).
Без Docker данные пишутся в `./data`, настройки — в `./config.yaml`.
